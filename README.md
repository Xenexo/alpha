# Alpha

A versatile AI-powered application supporting cloud, bring-your-own-key (BYOK), and local AI models.

## Features

- **Cloud AI Support**: Seamless integration with cloud-based AI providers
- **BYOK (Bring Your Own Key)**: Use your own API keys for flexibility and control
- **Local AI Models**: Run AI models locally for privacy and offline capability
- **Cross-platform**: Works on macOS, Windows, and Linux

## Setup

1. **Install Dependencies**: `npm install`
2. **Configure**: Set up your preferred AI provider (cloud, BYOK, or local)
3. **Run the App**: `npm start`

## Usage

1. Choose your AI provider in settings
2. Configure API keys or model paths as needed
3. Start using the application

## Requirements

- Node.js and npm
- Appropriate permissions for your OS
- API keys or local model files depending on your configuration
